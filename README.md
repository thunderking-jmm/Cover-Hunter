# Cover-Hunter
Descarga carátulas de canciones y de ROMs de juegos. Gratis, sin anuncios y sin versión de pago. Si te resulta útil y quieres apoyar el proyecto, puedes donar la cantidad que tú quieras. Eso me motiva a seguir mejorándolo. Si no, compartirlo también es una manera de aportar. Saber que te ayuda es suficiente pago para mí.
