# Cover Hunter

**Descarga carátulas de canciones y de ROMs de videojuegos de forma sencilla.**

Cover Hunter es una herramienta portable diseñada para buscar y descargar carátulas de música y videojuegos. Permite procesar colecciones completas, configurar las descargas y organizar las imágenes de forma automática.

Gratis, sin anuncios y sin versiones de pago.

## Características principales

### 🎵 Pestaña Audio

Permite buscar y descargar carátulas para archivos de audio, con diferentes opciones para personalizar el proceso.

- **Carpeta de canciones:** selecciona el directorio que contiene los archivos de audio que deseas procesar.
- **Carpeta de destino:** establece dónde se guardarán las imágenes descargadas. Si se deja vacía, las imágenes se guardarán junto a los archivos de audio.
- **URL / listado:** introduce manualmente una URL o listado de un repositorio de imágenes, si dispones de uno.
- **Calidad:** selecciona la calidad de las imágenes descargadas.
- **Simultáneas:** configura el número de descargas que se realizarán en paralelo.
- **Incrustar:** inserta directamente la imagen descargada en los metadatos del archivo de audio. De este modo, la carátula queda almacenada dentro del propio archivo y puede visualizarse en reproductores compatibles sin necesidad de disponer de una imagen externa.
- **Saltar:** evita volver a descargar carátulas en canciones que ya tienen una imagen incrustada.
- **Imagen por carpeta:** permite guardar una única imagen por álbum. Es especialmente útil cuando varias canciones pertenecen al mismo álbum y comparten carátula, evitando generar imágenes duplicadas.

### 🎮 Pestaña Juegos

- **Carpeta de juegos:** selecciona el directorio que contiene las ROMs de videojuegos.
- **Carpeta de destino:** establece dónde se guardarán las imágenes descargadas. Si se deja vacía, se utilizará la carpeta de las ROMs.
- **URL / listado:** introduce manualmente la URL de un repositorio o listado de imágenes, si dispones de uno.
- **Sistema:** selecciona la consola o sistema correspondiente de la lista disponible.
- **Tipo de imagen:** elige qué contenido deseas descargar: carátulas, capturas de pantalla, pantallas de título o todas las opciones.
- **Calidad:** selecciona la calidad de las imágenes descargadas.
- **Simultáneas:** configura el número de descargas que se realizarán en paralelo.
- **Eliminar duplicadas:** elimina las imágenes duplicadas una vez finalizado el proceso.
- **Descargar:** inicia el proceso de descarga.
- **Detener:** interrumpe el proceso de descarga en curso.

### 🖱️ Arrastrar y soltar

La interfaz admite la función de arrastrar y soltar en ambas pestañas.

Puedes arrastrar directamente archivos, carpetas e imágenes a la aplicación para agilizar y facilitar el trabajo.
